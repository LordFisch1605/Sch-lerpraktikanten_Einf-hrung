# Level 1.1 – Schleife

## Neu
- **`while`-Schleife** – wiederholt einen Code-Block, solange eine Bedingung `true` ist
- **`boolean`-Variable als Schalter** – `weitermachen = true/false` steuert, ob die Schleife
  weiterläuft oder abbricht

## Vergleiche mit dem vorherigen Level

In Level 1.0 lief das Programm genau einmal durch und endete.
Hier wird der gesamte Ablauf (Menü anzeigen → Auswahl lesen → Rechnen) in eine
`while`-Schleife eingebettet. Die einzige Neuerung im Diff ist genau das –
der Rest des Codes ist identisch zu Level 1.0.
