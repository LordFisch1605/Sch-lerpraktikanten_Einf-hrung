# Level 1.0 – Prozedural

## Neu
- **Variablen & Datentypen** – `int` für ganze Zahlen, `double` für Dezimalzahlen
- **Scanner** – liest Tastatureingaben ein (`scanner.nextInt()`, `scanner.nextDouble()`)
- **if / else if / else** – verzweigt den Programmfluss je nach Eingabe
- **Sonderfall Division durch 0** – wird manuell mit einer `if`-Bedingung abgefangen

Der gesamte Code läuft **direkt in der `main`-Methode** von oben nach unten durch –
das ist der prozedurale Programmierstil. Kein OOP, keine eigenen Methoden.

## Vergleiche mit dem vorherigen Level

Dies ist das **erste Level** – es gibt nichts davor. Schau dir an, wie der Code
von oben nach unten gelesen werden kann wie eine Schritt-für-Schritt-Anleitung.

hintereinander machen kann, ohne das Programm neu zu starten?
