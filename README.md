# Schülerpraktikanten-Einführung

Taschenrechner-Beispielprojekt zur Einführung in Java – von prozedural bis GUI.

## Projektstruktur

```
level1_prozedural/        Lineares Programm, kein OOP
level2_methoden/          Statische Methoden und Schleifen
level3_objektorientiert/  Objektorientierung, Klassen, Kapselung
level4_gui/               Grafische Oberfläche mit Swing
```

Jedes Level baut auf den Konzepten des vorherigen auf.  
Ein `tests/`-Unterordner ist in jedem Level für spätere Unit-Tests reserviert.

## Branch `archiv`

Enthält Entwurfs-Code aus dem `Beispiele/`-Ordner (Interface-Muster, Switch-Expressions),
der als Referenz aufbewahrt wird, aber nicht Teil der Levels ist.
